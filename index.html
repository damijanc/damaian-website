What is Damaian?

A desktop assistant that works on a Git repository on your machine. It reads your code to answer questions, proposes changes you can inspect, and never acts behind your back.

Up and running in three steps

  1. 01Open a project

    Select + beside Projects and pick a local Git repository.

  2. 02Add your model

    Open Settings (⌘ ,), add your provider and store the API key in the Keychain.

  3. 03Ask or change

    Ask about the code, or request a change like “add a test for the config parser” and review the diff.

Built for control

Damaian runs locally against your own checkout. Your model key lives in the macOS Keychain, and credentials it detects are redacted from context, command output, diffs and exports.

Consent screens show the full command or change. Nothing is pre-selected toward approval, and anything that outlives the turn, like “always allow”, sits behind an extra click.
